# N4 Clocking v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend vita's N4 clocking from INPUT-only (v1) to also support explicit `#1step` input skew (accepted as no-op), anonymous clocking blocks (no loud error), and OUTPUT direction drive (simplified synchronous model — `holding_net → source_net` committed at each clocking edge in the Active region).

**Architecture:** All IR-0, no frozen SimIr format change. Three sidecar additions in SimOpts (out-of-band, golden-free): `clocking_outputs: BTreeMap<ProcId, Vec<(source_net, holding_net)>>` for output pairs. The existing commit-handler proc (already synthesized per clocking block) is extended to also drive outputs after its INPUT phase. Anonymous blocks use synthetic name `"__anon_N"` internally. Byte-identical invariant: designs without OUTPUT ports or anonymous blocks have empty new sidecars → zero-cost code path.

**Tech Stack:** Rust 1.82, `crates/elaborate/src/lib.rs` (lowering), `crates/sim-engine/src/state.rs` (commit handler + SimState), `crates/sim-engine/src/sched.rs` (scheduler wire), `crates/cli/tests/clocking_n4.rs` (TDD test bed). Oracle: hand-IEEE (iverilog 13 does not support clocking blocks).

**Format version:** 19 → 19 (NO CHANGE — all additions are out-of-band sidecar only)
**MsgCode count:** 57 → 57 (NO CHANGE)

## Task 3: Output Driver — Simplified Synchronous Model

Add OUTPUT direction support. Model: at each clocking edge, the commit handler drives `source_net = current_value(holding_net)` (blocking, Active region, after INPUT commits). This differs from the IEEE Observed/Reactive model (no explicit region) but covers the common testbench pattern correctly. Pinned as hand-IEEE.

**Key invariants:**
1. OUTPUT holding net is WRITABLE (not in `clocking_hold_nets`).
2. `commit_clocking` extends: after INPUT phase, iterate `clocking_outputs[pid]` and drive each source from its holding.
3. Designs with no output clocking items: `clocking_outputs` is empty → `commit_clocking` skips output phase → byte-identical to v1.

- Modify: `crates/sim-engine/src/lib.rs` — add `clocking_outputs` to `SimOpts`, wire into `simulate`

**Interfaces:**

```rust
pub(crate) fn commit_clocking(&mut self, proc: u32) -> bool {
    let is_input_handler = self.clocking_commit.contains_key(&proc);
    let is_output_handler = self.clocking_outputs.contains_key(&proc);
    if !is_input_handler && !is_output_handler {
        return false;
    }
    // INPUT phase: preponed_buf[source] → holding_net (existing).
    if let Some(pairs) = self.clocking_commit.get(&proc).cloned() {
        for (hold, src) in pairs {
            if let Some(v) = self.preponed_buf.get(&src).cloned() {
                self.commit_clocking_sample(hold, &v);
            }
        }
    }
    // OUTPUT phase: current_value(holding_net) → source_net (new).
    // Simplified synchronous model: drive in Active region at edge detection,
    // after INPUT commits. Hand-IEEE (no Reactive region; covers typical TB use).
    if let Some(out_pairs) = self.clocking_outputs.get(&proc).cloned() {
        for (src, hold) in out_pairs {
            let v = self.read_net(hold, None);
            self.commit_clocking_sample(src, &v);
        }
    }
    true
}
```

```rust
    ast::ClockingDir::Output => {
        // OUTPUT: synthesize a WRITABLE holding reg + drive source at each edge.
        // Simplified synchronous model: `source = holding` in Active region at edge.
        // (No Observed/Reactive region — hand-IEEE, covers common TB patterns.)

            None => it.name.name.clone(),
            Some(e) => match &e.kind {
                ast::ExprKind::Ident(p) => p.segments.iter()
                    .map(|s| s.name.as_str()).collect::<Vec<_>>().join("."),
                _ => {
                    self.error(MsgCode::ElabUnsupported,
                        "a clocking output bind must be a net reference in this subset");
                    continue;
                }
            },
        };
        let Some(src_id) = self.lookup_net_scoped(&src_name) else {
            self.error(MsgCode::ElabUnresolvedName,
                &format!("undeclared clocking output signal `{}`", self.fq(&src_name)));
            continue;
        };

        let nv = ir::NetVar {
            kind: ir::NetKind::Reg,
            width: w, msb, lsb, signed,
            array_len: 1,
            dir: ir::PortDir::Internal,
            init: default_init(ast::NetVarKind::Reg, w), // X-init
        };
        let hid_before = self.nets.len() as u32;
        self.add_net(&clean, nv);
        let hid = self.lookup_net_scoped(&clean).unwrap_or(hid_before);
        // Alias `cb.sig` → holding net (writable — NOT added to clocking_hold_nets).
        let alias = self.fq(&format!("{}.{}", cb_name, it.name.name));
        self.symbols.insert(alias, hid);
        // Store output pair for this block's commit proc.
        out_pairs.push((src_id, hid)); // (source_net, holding_net)
        continue;
    }
    ast::ClockingDir::Inout => {
        self.error(MsgCode::ElabUnsupported,
            "a clocking INOUT driver is unsupported in this subset");
        continue;
    }
}
```
