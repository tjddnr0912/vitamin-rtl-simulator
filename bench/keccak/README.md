# bench/keccak — Keccak-f[1600], first-party

Unlike the rest of `bench/`, this RTL is written in this repository and is committed,
so every measurement taken on it reproduces without a network. FIPS 202, one
permutation round per clock, 1600-bit flat port.

Two corpus rows are built from these files. The recipe, the pinned digest and the
oracle are in [RUN.md](RUN.md); the cross-corpus timing table is
[docs/study/03-workload-corpus.md](../../docs/study/03-workload-corpus.md).

| File | What |
|---|---|
| `keccak_f.sv` | the readable core — a `rho` offset table and a `rotl64` as user functions |
| `keccak_f_arr.sv` | the same design, except that `rho` builds a 25-element `integer` array on every call |
| `keccak_f_flat.sv` | generated by `gen_flat.py` — every user-function call expanded inline |
| `tb.sv` | chains `+N=<count>` permutations and prints two lanes plus their xor |

## Three spellings of one algorithm

All three compute the same permutation and print the same line at every `N`. They
differ only in how the round function is spelled, which is what makes the set a
measurement rather than three designs.

`keccak_f.sv` and `keccak_f_arr.sv` differ in nothing but how `rho` looks up a
constant. That one difference is the corpus's worst case for vita: it is the
`keccak-arr` row, and the only design any arena estimate has been computed from.

`keccak_f_flat.sv` is deliberately not a corpus row. It is the flat half of the
call-regime pair — the same algorithm with no subroutine call left in it, which is what
isolates the cost of the call itself
([study 01](../../docs/study/01-interpreted-vs-compiled.md) §2.4). Regenerate it from
this directory with `python3 gen_flat.py`; it overwrites `keccak_f_flat.sv` in place.

## Oracle

Four independent implementations agree at every `N`: a Python reference, vita, Icarus
Verilog 13 and Verilator 5.050. The agreement is anchored rather than merely mutual —
at `+N=1` the state starts all-zero, so the first lane must be the published Keccak
value `f1258f7940e1dde7`:

```sh
../../target/release/vita tb.sv keccak_f.sv +N=1
perms=1 lane0=f1258f7940e1dde7 lane1=84d5ccf933c0478a acc=584777e2b448a416
```

The same three-way check at any size, from this directory:

```sh
../../target/release/vita tb.sv keccak_f.sv +N=200
iverilog -g2012 -o k.vvp tb.sv keccak_f.sv && vvp k.vvp +N=200
verilator --binary --timing -Wno-fatal -o vk tb.sv keccak_f.sv && ./obj_dir/vk +N=200
```
