# bench/ — the workload corpus

Real RTL, fetched at a pinned commit, run under `vita`, checked against a digest an
external oracle produced. The tool is `crates/corpus-runner`; the write-up is
[docs/study/03-workload-corpus.md](../docs/study/03-workload-corpus.md).

```sh
cargo run -p corpus-runner -- list          # what the corpus contains
cargo run -p corpus-runner -- fetch --run   # clone each design at its pinned SHA
cargo run -p corpus-runner -- run --compare # run everything, check every digest
```

## What is committed here, and what is not

Two kinds of thing live under `bench/`, and they are treated oppositely.

| | committed? | why |
|---|---|---|
| **Testbenches, file lists, `RUN.md`, `run.sh`, `prepare.sh`, `mkhex.py`** | **yes** | first-party work product. A pinned SHA reconstructs the upstream RTL but *not* the harness — and the harness is what produced the digest |
| **`bench/*/src/`** — the upstream clone | **no** | third-party RTL under eight different licences. Never redistributed by this project; `corpus-runner fetch --run` clones it at the pinned SHA |
| **Firmware images** (`prog.hex`, `blinky.hex`) | **no** | also upstream content: one is byte-identical to serv's own `sw/blinky.hex`, the other is extracted from biriscv's `test.elf`. Referenced inside the clone, or regenerated by `prepare.sh` |
| **`bench/keccak/*.sv`** | **yes** | first-party RTL written in this repository (see its README) |
| **Build products** (`*.vvp`, `obj_dir/`, simulator binaries, logs) | **no** | — |

`.gitignore` implements this as an **allow-list**: everything under `bench/` is
ignored unless it matches a named pattern, so a stray binary or scratch probe cannot
be committed by accident.

## The contract every workload obeys

1. **Permissive licence** — MIT / BSD-2 / BSD-3 / ISC / Apache-2.0. A test enforces it.
2. **An oracle ran it first.** No oracle, no admission — `ibex` was turned away on
   exactly this ground (iverilog 13 cannot parse it at all).
3. **One `DIGEST=` line, accumulated over the whole run.** Not final state: a
   final-state comparison is blind to a divergence the design later overwrites.
4. **Deterministic and self-terminating** — explicit `$finish`, fixed seeds, watchdog.
5. **The digest must move when the design changes.** Mutate one line of the upstream
   RTL and re-run: if the digest survives, the workload is not gating anything and
   looks exactly like one that is. `picorv32` failed this — its program never stored,
   so nothing it computed reached the bus, and inverting the core's adder left the
   digest byte-identical. Beware dead mutations: in the `verilog-ethernet` loopback
   TX and RX share one `lfsr`, so a CRC change cancels at both ends.

## Refusals are part of the corpus

Three of the eight third-party designs are refused by vita today, and the manifest
records each one with the diagnostic it produces. That is not a gap in the corpus,
it is the corpus doing its job: `corpus-runner run` grades a pinned refusal as
`known-gap` (green), a *different* refusal as `DRIFTED` (red), and a design that
starts running as `PROMOTED`. See ROADMAP §3.
